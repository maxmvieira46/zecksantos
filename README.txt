ZECK SANTOS | Site V3 Final

Como abrir
1. Extraia o ZIP completo.
2. Abra index.html em um navegador moderno.
3. Para publicar, envie toda a pasta para GitHub Pages, Netlify, Vercel ou outra hospedagem estatica.

Melhorias da V3
- Carrossel automatico dos quatro looks do hero, com troca a cada 3 segundos e selecao manual.
- Croqui e projecao em dois estados diretos, alternados com um clique.
- Destaque cromatico da peca individual dentro de looks completos.
- Engenharia invisivel reorganizada em cinco camadas selecionaveis, com legenda, descricao e visao explodida.
- Lookbook automatico a cada 5 segundos, com setas, arraste, teclado, contador e barra de progresso.
- Textos instrucionais reduzidos e integrados de forma mais discreta.
- Ajustes de acessibilidade, navegacao, responsividade e reducao de movimento.

Observacao
As imagens de projecao sao interpretacoes conceituais previamente produzidas. A geracao de novas imagens em tempo real exigiria integracao com uma API e um backend.


ATUALIZAÇÃO V3.1
