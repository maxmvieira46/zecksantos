# ZECK SANTOS - Inverno 2027 - Versao 3 atualizada

Site estatico em HTML, CSS e JavaScript puro.

## Abrir localmente

A opcao mais simples e abrir `index.html` no navegador.

Para evitar restricoes locais e testar como em hospedagem:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Publicacao

O projeto pode ser publicado em GitHub Pages, Netlify, Vercel ou qualquer hospedagem estatica.

## Imagens

As 16 imagens foram organizadas em oito familias cromaticas com duas direcoes visuais por familia. As imagens atuais foram preparadas a partir dos paineis fornecidos. Quando os arquivos individuais 4:5 estiverem disponiveis, substitua os arquivos em `assets/images/looks` mantendo os mesmos nomes.

## Formulario

O formulario esta em modo demonstrativo e nao envia dados. Configure Formspree, Netlify Forms ou um endpoint proprio antes da publicacao.
